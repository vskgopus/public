Embedded System Training

A course for embedded software engineers, from a refresher of the fundamentals up to expert topics for engineers with more than 3 years of experience, including DO-178C airborne software certification.

Each of modules 1–4 has Beginner, Intermediate and Advanced sections as a refresher, followed by an Expert section on safety-critical and certification-oriented practice. Module 5 covers DO-178C from overview to audit-level detail.

# Module Expert topics
1 Embedded C MISRA C and the essential type model, integer and aliasing traps, volatile vs atomics, bounded stack and WCET, fixed point, static analysis
2 MCU & Peripherals Cache/DMA coherency, memory barriers, register races, MPU, errata, built-in test, ECC scrubbing
3 Communication Protocols End-to-end message integrity, safe parsing, CAN error confinement and timing, ARINC 429, MIL-STD-1553B, AFDX
4 RTOS Response-time analysis, priority ceiling, ARINC 653 partitioning, multicore interference, certified RTOS use
5 DO-178C Software levels, plans and standards, requirements-based testing, MC/DC, coverage gaps, tool qualification (DO-330), supplements

Expert quiz

▶ Start the expert MCQ quiz

  • 60 scenario questions written for engineers with 3+ years of experience: 12 per module, including DO-178C. Many involve reading code, debugging a symptom or making a certification decision.
  • Choose one module or all modules, and 10, 20, 30 or all questions. Questions and options are shuffled on every attempt.
  • At the end you see your score, pass/fail status (pass mark 70 %), a per-module breakdown and an explanation for every question.
  • Download your result as a CSV file or print / save it as a PDF report.

Note: the result report is generated in your browser and is not stored on any server. It is a self-assessment record, not a tamper-proof certificate.

DO-178C disclaimer: this course summarises DO-178C for training only. It doesn't replace the RTCA/EUROCAE documents or your certification authority's guidance.

Suggested study path

  1. Skim the Beginner to Advanced sections of each module as a refresher, and read the Expert section closely.
  2. Read Module 5 (DO-178C), then go back to the "certification" notes in modules 1–4.
  3. Take each module's quiz, then the combined 60-question quiz.
