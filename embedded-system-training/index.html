Embedded System Training

A self-paced course for beginners through intermediate engineers. Each module is split into Beginner, Intermediate and Advanced sections. When you finish, take the online MCQ quiz and download your result report.

# Module Topics
1 Embedded C Basics stdint.h, bit manipulation, volatile/const/static, memory layout, undefined behaviour
2 MCU & Peripherals GPIO, interrupts/NVIC, timers, PWM, ADC, DMA, watchdog, low power
3 Communication Protocols UART, SPI, I2C, CAN
4 RTOS Fundamentals Tasks, scheduling, queues, semaphores, mutexes, priority inversion

Online quiz

▶ Start the MCQ quiz

  • Choose a module (or all modules) and a difficulty level.
  • Questions and answer options are shuffled on every attempt.
  • At the end you see your score, pass/fail status (pass mark 70 %), a per-module breakdown and an explanation for every question.
  • Download your result as a CSV file or print / save it as a PDF report.

Note: the result report is generated in your browser and is not stored on any server. It is a self-assessment record, not a tamper-proof certificate.

Suggested study path

  1. Read a module from top to bottom, then try the self-check questions at the end.
  2. Take that module's quiz at the Beginner level, then All levels.
  3. After all four modules, take the combined quiz.
