  • Embedded

    LinkView

    A linker script and map file viewer for firmware. Draws a GNU ld linker script as a memory map (regions, sections, load and run addresses, overlays, segments) and lists mistakes with suggested fixes. Reads GNU ld and LLD map files to show how full each region is and which files take the space, and can put the real section sizes onto the script's diagram. Nothing is uploaded.

  • Course

    Embedded System Training

    An embedded software course from fundamentals to expert level (3+ years), covering embedded C, MCU peripherals, UART/SPI/I2C/CAN and avionics buses, RTOS, DO-178C certification and MC/DC, with diagrams, a 516-question expert quiz (25 random questions per module per attempt) and a downloadable result report.

  • Tools

    Sandboxed Tools

    Free in-browser tools that run on your device, with nothing uploaded. PDF Studio cleans scanned pages to a white background with crisp text, merges, splits, reorders and rotates pages, makes several-pages-per-sheet collages, makes scans searchable with OCR, lets you zoom in to check the result, and downloads or prints it. Passport Photo crops to the passport size of your country, replaces the background, evens out the lighting, removes stickers or marks you paint over, and prints a sheet of copies. Document Scanner turns a phone photo of a page into a flat, clean scan (PDF or image), several pages at a time, and puts both sides of an ID card at true size on one sheet.

    Rust for C Programmers

    A free online book that teaches Rust to experienced C developers by mapping each Rust concept onto the C pattern and memory model you already know: ownership, borrowing, lifetimes, traits, unsafe, FFI, concurrency and no_std. 25 chapters with runnable snippets, exercises with solutions, appendices and a downloadable PDF.
