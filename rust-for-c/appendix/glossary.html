Rust for C Programmers

Glossary

Rust terms, each with the C idea it corresponds to and the chapter that teaches it. Terms the book leaves out are listed at the end.

This page is a lookup table, not a chapter, so it does not follow the six-section template.

TermMeaningC counterpartChapter

trait objectA value used through dyn Trait, dispatched at run time through a vtableA struct holding function pointers16
turbofishThe ::<T> syntax for naming a type parameter at a call, as in parse::<u16>()None14
